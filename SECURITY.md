# Security Policy

## Supported Versions

The following versions of TallerSmart currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do NOT create a public GitHub issue. Instead, report it privately:

1. Email our security team at `security@tallersmart.local` with details of the vulnerability, affected components, and steps to reproduce.
2. If applicable, provide a Proof of Concept (PoC).
3. We will acknowledge receipt of your vulnerability report within 48 hours and provide a timeline for remediation.
4. Coordinated disclosure will be respected prior to any public advisory.
